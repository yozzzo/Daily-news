**何ができるようになったか**  
舗装されていない悪路（未舗装路・砂利道・荒れ地）での4D（時間+3D空間）再構成が、カメラ位置情報なしでリアルタイムに可能になった。

**これまでの課題と解決策**  
これまでの4DGS手法は整備された道路環境を前提として設計されており、不規則な地形・揺れの多い映像・激しく動く被写体が多いオフロードシーンでは精度が大幅に低下していた。Ground4Dは「ボクセル（立体格子）単位の時空間アテンション」と「法線方向の幾何的ガイダンス」を組み合わせ、カメラのポーズ推定不要でオフロードシーンを高精度に4D再構成する。

**影響範囲**: ロボット・農業機械・建設機械・軍事・探査ローバーなど非舗装路動作の全シーン

### 2. ArtifactWorld — ビデオ生成AIで3DGSのアーティファクトを大規模自動修復

| **重要度** | ★★★★★ |

**何ができるようになったか**  
少ない枚数の写真から作成した3DGSシーンに生じる「幽霊のような浮遊物」「ぼやけ」「穴」「引き伸ばされたノイズ」などの欠陥を、AIが自動で分類・修復できるようになった。

**これまでの課題と解決策**  
3DGSは撮影枚数が少ないと様々な種類の「アーティファクト（欠陥）」が発生するが、その修正は手作業が必要だった。ArtifactWorldは欠陥を4ドメイン9種類に体系的に分類し、1万6千の高品質シーンから2万5600の欠陥ペア動画データセットを自動生成。ビデオ生成AIで欠陥シーンを修復する初の大規模フレームワークを構築した。

**影響範囲**: 不動産・文化財・建築可視化など、写真枚数が限られる現場のGS品質が飛躍的向上

### 3. MesonGS++ — 学習ゼロで34倍圧縮・目標ファイルサイズを指定可能

| 項目 | 内容 |
|------|------|
| **論文ID** | [arXiv:2604.26799](https://arxiv.org/abs/2604.26799) |
| **投稿日** | 2026年4月29日 |
| **分野** | 3DGS圧縮・最適化 |
| **重要度** | ★★★★★ |

**何ができるようになったか**  
既存の3DGSモデルを、再学習ゼロで最大34倍に圧縮できる。しかも「目標ファイルサイズを指定する」だけで自動的に最適な圧縮設定を導き出してくれる。

**これまでの課題と解決策**  
3DGSのファイルは1シーン数百MB〜数GBにもなり、モバイルアプリやWebへのデプロイが困難だった。MesonGS++はガウシアンの重要度スコアリング・属性変換・整数線形計画による量子化ビット配分を組み合わせ、20倍圧縮では元の3DGSより高い画質（PSNR）を達成。追加学習不要なので既存モデルにそのまま適用できる。

**影響範囲**: AR/VR・スマートフォン・Webビューア向けの3DGS配信コストを劇的削減

**何ができるようになったか**

### 7. Hybrid 3D-4D Gaussian Splatting — 静的/動的を自動分離するハイブリッドGS（ICLR 2026）

| 項目 | 内容 |
|------|------|

| **掲載** | ICLR 2026 |

| **重要度** | ★★★★★ |

**何ができるようになったか**  
動画から3Dシーンを再構成する際に、「動かない背景」は軽い3DGSで、「動く物体」だけは4DGSで表現するという自動切り替えが実現した。品質を維持しながら学習時間・メモリ使用量を大幅削減できる。

**これまでの課題と解決策**

**影響範囲**: 動的シーン再構成の研究・実装コスト削減。映画・ゲーム・ロボット訓練データ生成に直結

### 8. Faster 3DGS Convergence via Structure-Aware Densification — 構造認識で3DGS学習を高速化

| 項目 | 内容 |
|------|------|
| **論文ID** | [arXiv:2604.28016](https://arxiv.org/abs/2604.28016) |
| **投稿日** | 2026年4月30日 |
| **分野** | 3DGS最適化・学習高速化 |
| **重要度** | ★★★☆☆ |

**何ができるようになったか**  
3DGSの学習（最適化）が「構造を意識した早期増殖」によって大幅に高速化できるようになった。FastGSなど最新の高速化手法と比較しても、より速い収束を実現。

**これまでの課題と解決策**  
標準的な3DGSの「適応的密度制御（Adaptive Density Control）」は、位置の勾配だけを見るためテクスチャの細かさと位置の誤りを区別できず、高周波テクスチャが過度にぼかされたり非効率が生じていた。本手法はガウシアンのスクリーン空間上の大きさと表現すべきテクスチャ構造を直接比較し、適切なタイミングで分割する。Max-Planck研究所・ケンブリッジ大学の共同研究。
