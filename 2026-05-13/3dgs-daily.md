## 📚 注目論文

### 1. AdpSplit — 誤差駆動の適応分割で訓練時間を最大22%削減

- **arXiv**: [2605.06876](https://arxiv.org/abs/2605.06876)
- **投稿日**: 2026年5月7日
- **重要度**: ★★★★☆

**何ができるようになったか**  
3DGSの学習（訓練）プロセスで、ガウシアンを「分裂」させる処理（スプリット）を改良した手法。従来は固定ルールで分裂させていたが、実際にレンダリングで誤差が大きいピクセル領域を見つけて、そこに合わせた数・形状の子ガウシアンを生成する。これにより反復回数を減らしながら同品質を維持でき、訓練時間を**9.2〜22.3%削減**。既存の高速3DGSパイプラインにほぼそのまま組み込める「ドロップイン」方式。

**これまでの課題と解決策**  
従来の3DGSは分裂を何度も繰り返さないと細部が再現できず、それがボトルネックだった。AdpSplitは誤差の大きい場所を優先的に分割することで、少ない反復で同品質を達成する。

### 2. Relightable GS for Virtual Production — LEDウォール専用の再照明フレームワーク

- **arXiv**: [2605.09024](https://arxiv.org/abs/2605.09024)
- **投稿日**: 2026年5月9日
- **重要度**: ★★★★★

**何ができるようになったか**  
映画・TVドラマ制作で使われる「LEDウォール（巨大LEDスクリーンをスタジオに設置してCGと実写を合成する手法）」向けに特化した3DGS再照明技術。LEDウォールが映像と照明を同時に担う特性を活かし、環境マップに依存せず背景画像から照明を直接推定する。**使用メモリ3GB以下・VRAM5GB以下・訓練2時間以内・約35FPS**でリアルタイム表示可能。

**これまでの課題と解決策**  
バーチャルプロダクションではLEDウォールが「照明」と「背景」を同時に担うため、後から照明を変えたいときに制約が大きかった。本手法はGSを照明の固定成分と可変成分に分離し、背景映像を変えるだけで再照明を実現する。

### 3. TIGAS — HTTP/3でGSシンクライアントストリーミング

- **arXiv**: [2605.08699](https://arxiv.org/abs/2605.08699)
- **投稿日**: 2026年5月9日
- **重要度**: ★★★★☆

**何ができるようになったか**  
スマホや低スペックPCでもGSを快適に操作できるよう、重いレンダリング処理をサーバー側で実行し、結果の2D映像だけをHTTP/3（QUIC）プロトコルで端末に送るシステム。QUICは従来HTTPと比べて「頭打ち問題（前のデータが届かないと全体が止まる）」が少なく、低遅延でインタラクティブ操作が可能になる。

**これまでの課題と解決策**  
GSは処理が重いため、スマホや低スペック端末では動作が困難だった。レンダリングをサーバー側に移すことでクライアント側の負荷をほぼゼロにし、映像ストリームだけで本格的な自由視点映像体験を実現する。

### 4. CAGS — 色適応型ボリューメトリックビデオ動的GS配信

- **arXiv**: [2605.09279](https://arxiv.org/abs/2605.09279)
- **投稿日**: 2026年5月10日
- **重要度**: ★★★★☆

**何ができるようになったか**  
動的3DGS（4DGS）を使ったボリューメトリックビデオ（人や物が立体的に動く映像）を、通信帯域に応じて**色・品質を自動調整**しながらリアルタイム配信する技術。テレプレゼンス（遠隔で「その場にいる感覚」）、生態系モニタリング、ロボット遠隔操作などへの応用を想定。

**これまでの課題と解決策**  
既存のLoD（距離ベースの品質調整）はGSの表現とそもそも相性が悪く、品質を下げると見た目に大きな粗が出た。CAGSは色情報を適応的に調整することで、帯域制限下でも自然な品質劣化で配信を維持する。

### 5. Flow4DGS-SLAM — 光学フロー誘導で動的環境の4D地図作成

- **arXiv**: [2604.22339](https://arxiv.org/abs/2604.22339)
- **投稿日**: 2026年4月24日
- **重要度**: ★★★★☆

**何ができるようになったか**  
ロボット・自動運転で使われるSLAM（カメラで周囲の地図を作りながら自分の位置も把握する技術）に4DGSを応用。映像の動きベクトル（光学フロー）と深度情報を組み合わせ、動的ガウシアン（動く物体）と静的ガウシアン（建物・道路等）を自動的に分離することで、人や車が動き回る環境でも高精度なSLAMを実現。

**これまでの課題と解決策**  
従来のSLAMは動いている物体が「ノイズ」として扱われ、精度を著しく落とした。光学フローでカメラ自身の動きと外部の動きを分解し、4DGSで時空間を統合的にモデリングすることでこの問題を解決。

### 6. Sony XYN Spatial Capture Solution — ソニーが業務用GS制作ツールを正式発表

- **発表日**: 2026年4月15日
- **URL**: [xyn.sony.net](https://xyn.sony.net/en/news/2026-spatial-press)
- **重要度**: ★★★★★

**何ができるようになったか**  
ソニーが映像制作プロ向けに3DGSベースの空間キャプチャソリューション「XYN（ジン）」を正式発表。3つのツールで構成：
- **XYN Spatial Scan Navi**（スマホアプリ：撮影ガイド）
- **XYN Spatial Scan**（クラウド：GS生成）
- **XYN Spatial Renderer Plugin**（Unreal Engine 5向けレンダリングプラグイン）

LEDウォールを使ったバーチャルプロダクション（映画・ドラマ撮影）に最適化。HDR対応で光の照り返しや遠景の霞まで高精度に再現。NAB Show 2026で展示、**2026年夏より米国の業務向けに提供開始**予定。Disguise等の既存プロダクション機材とも連携。

**意義**: ソニーという大手映像メーカーがGSを主力製品ラインに統合したことで、バーチャルプロダクション市場でのGS採用が大幅に加速する見通し。

### 7. SimActive Correlator3D Version 11 — 測量・フォトグラメトリー業界にGSが正式統合

- **発表日**: 2026年5月12日（XPONENTIAL 2026、デトロイト）
- **URL**: [dronelife.com](https://dronelife.com/2026/05/12/gaussian-splatting-photogrammetry-simactive-correlator3d/)
- **重要度**: ★★★★★

**何ができるようになったか**  
カナダの大手測量ソフトSimActiveが「Correlator3D Version 11」でGaussian Splattingを統合。ドローン撮影映像から**従来の測量データ（GIS対応・精度保証あり）とGSモデルを同一ソフトウェア内で同時生成**できるようになった。ユーザーはソフトを切り替えることなく、正確な地理空間データとフォトリアルな3D映像の両方を出力できる。

**意義**: 「測量精度 vs GSのリッチな視覚表現は相反する」という認識を覆し、建設・インフラ・環境調査分野での本格的なGS展開が始まった。

## 💬 コミュニティ・SNS話題

### 8. BlendSplat — BlenderでGSをノードベースでネイティブ編集

- **URL**: [radiancefields.com](https://radiancefields.com/blendsplat-gaussian-splatting-in-blender-natively)
- **重要度**: ★★★★☆

BlenderのGeometry Nodes（手続き型グラフ操作ツール）とEEVEEレンダラーを使って、GaussianSplatsをBlender内で追加・変形・レンダリングできる無料ツールキット。外部ソフト不要でBlenderのプロシージャルワークフロー（インスタンス化・変形等）をGSに適用可能。被写界深度やモーションブラーも通常のBlenderカメラ設定で動作。Gumroadで無料公開。

---

### 9. GaussianSplats3D（Three.js版）— Webブラウザで2DGSが閲覧可能に

- **URL**: [github.com/mkkellogg/GaussianSplats3D](https://github.com/mkkellogg/GaussianSplats3D)
- **重要度**: ★★★☆☆

WebブラウザでGSを表示する人気ライブラリ「GaussianSplats3D」（Three.js実装）が2DGS（SurfSplatting）に対応。2DGSは平面状ガウシアンプリミティブを使い、物体表面の形状をより正確に捉えられる。パラメーター `splatRenderMode: SplatRenderMode.TwoD` で切り替え可能。1次・2次球面調和関数もサポートし、Web上でのGS品質が向上。

---

### 10. SuperSplat Studio 2.0 — 無料ブラウザ型GSエディタが本格制作環境に進化

- **URL**: [blog.playcanvas.com](https://blog.playcanvas.com/build-gaussian-splat-experiences-with-supersplat-studio/)
- **重要度**: ★★★★☆

PlayCanvasの無料GS編集ツール「SuperSplat」がStudio 2.0へと進化。主な新機能：
- 最大**25箇所のアノテーション（注釈・ホットスポット）** — カメラ視点付きで、クリックで自動移動
- **ポストエフェクト** — Bloom・シャープ・ビネット・色調整・収差
- **カメラアニメーション・フライスルー** — 自動巡回映像の作成
- **WebXR対応** — Meta Quest / Apple Vision Pro / スマホARで直接閲覧

不動産内覧、博物館ガイド、文化財保存など、インタラクティブ3D体験の制作に使える本格ツールへ。ブラウザから操作でインストール不要。

### 11. OpenSplat — オープンソースGS学習がMacでGPU加速に対応

- **URL**: [radiancefields.com](https://radiancefields.com/opensplat-3dgs-now-on-mac)
- **重要度**: ★★★☆☆

C++実装のオープンソース高性能GS学習ツール「OpenSplat」が**Apple Silicon・Intel Mac両方でのMPS（Metal Performance Shaders）GPU加速バックエンドに対応**。これまでWindows/Linuxが中心だったが、MacでもGPU加速で3DGSモデルの本格学習が可能になった。コミュニティから「MacユーザーのGS参入障壁が一気に下がった」と評価。
