# 3DGS & 4D生成 デイリーレポート（2026-06-19）

3D Gaussian Splatting（3DGS：無数の半透明な「ガウス点」を空間に配置して立体を表現する技術）と、それに時間軸を加えた4D Gaussian Splatting（4DGS）に関する最新動向をまとめました。今回は**論文6件・業界ニュース4件・コミュニティ話題3件**の合計13件を新規に紹介します（過去配信済みの項目は除外済み）。

## 今日の注目トレンド

1. **映画『スーパーマン』が4DGSを本編VFXに初採用** — Framestoreが実在の俳優の演技を「動く立体ホログラム」として撮影後も自由に視点変更できる形で映画に組み込んだ、業界的に大きな一歩
2. **手の動き専用の4D再構成技術が登場** — スマホやARグラスのカメラ映像だけで、手の3D動作を瞬時に復元できるように
3. **悪条件下（霧・サーマルカメラ）での3DGS対応が前進** — 視界の悪い環境でも3D化が可能に
4. **日本国内でも3DGS体験会・ミートアップが活発化** — 大企業だけでなく中小企業や個人クリエイターにも技術が浸透
5. **不動産・XRイベントでの実用導入が加速** — Apartments.comの3D外観ツアー、AWEでのUnity連携など商用化が着実に進行

## スレッド1: 注目論文（重要度：高）

### 1. GASE（Gaussian Splatting-based Automated System for Embodied-Simulation Environments）
- **何ができるようになったか**: 全方位（パノラマ）カメラの映像を使って、ロボット学習用のシミュレーション環境を高速・自動で構築できるようになった
- **これまでの課題と解決**: これまでロボット訓練用の3D環境を作るには手作業での詳細なモデリングが必要だったが、現実空間を撮影するだけで自動的に「ロボットが動き回れる仮想空間」に変換できるようになった
- リンク: https://arxiv.org/abs/2606.17520

### 2. Hand-4DGS
- **何ができるようになったか**: スマホやARグラスなど一人称視点（エゴセントリック）のカメラ映像から、手の3D動作をリアルタイムで再構成できるように
- **これまでの課題と解決**: 手は変形が激しく複雑なため3D化が難しかったが、フィードフォワード（一度の処理で即座に結果が出る）方式により、追加の学習なしで様々な手の動きに対応できるようになった
- リンク: https://arxiv.org/abs/2606.19156

### 3. Intrinsic 4D Gaussian Segmentation from Scene Cues
- **何ができるようになったか**: 動く3Dシーンの中で「どこが何の物体か」を自動で見分けられるように（4Dシーンのセグメンテーション=領域分け）
- **これまでの課題と解決**: 従来は動画の各フレームを個別に解析する必要があったが、シーン全体の手がかりを利用することで、時間を通じて一貫した物体の認識が可能になった
- リンク: https://arxiv.org/abs/2606.18623

### 4. Dehaze-GaussianImage
- **何ができるようになったか**: 霧やかすみがかかった写真でも、学習データなし（ゼロショット）でクリアな画像に復元しながら3D化できるように
- **これまでの課題と解決**: 悪天候の撮影データは3DGSの品質を大きく落としていたが、軽量な2Dガウシアン表現を使うことで、追加の事前学習なしに霧除去と3D表現を同時に行えるようになった
- リンク: https://arxiv.org/abs/2606.16163

### 5. Unpaired RGB-Thermal Gaussian-Splatting
- **何ができるようになったか**: 通常カメラ（RGB）とサーマル（熱）カメラの映像を、位置合わせ済みのペアデータなしで組み合わせて3D化できるように
- **これまでの課題と解決**: 夜間や悪視界でも使えるサーマルカメラとの統合は、両カメラの映像を正確に対応づけるデータ作成が大きな壁だったが、視覚幾何変換モデルを使うことでペアなしデータでも高精度に統合できるようになった
- リンク: https://arxiv.org/abs/2606.05491

### 6. ReefMapGS
- **何ができるようになったか**: 水中ロボットが、GPSも使えない海中環境でサンゴ礁などの広範囲を3D地図化できるように
- **これまでの課題と解決**: 水中では従来のカメラだけの位置推定（SfM）は計算負荷が高く実用困難だったが、音響・慣性・気圧センサーを組み合わせたSLAM（自己位置推定と地図作成を同時に行う技術）と3DGSを連携させることで、ロボットが動きながらリアルタイムに精度の高い3D地図を作れるようになった
- リンク: https://arxiv.org/abs/2604.11992

## スレッド2: 業界ニュース

### 7. 映画『スーパーマン』にFramestoreが4DGSを本編VFXとして初採用
- **何ができるようになったか**: 実在の俳優（ブラッドリー・クーパー、アンジェラ・サラフィアン）の演技を立体的に撮影し、編集時に自由にカメラ視点を変えられる「動くホログラム」を映画本編に実装
- **これまでの課題と解決**: 従来のVFXでは演者の演技後にカメラアングルを変更することはできなかったが、4DGSにより撮影後でも自由に視点・フレーミングを変更できるようになり、「CGっぽさ」を感じさせない自然な演技再現が実現した
- リンク: https://radiancefields.com/gaussian-splatting-in-superman

### 8. アクティブリテック×福井コンピュータ「3DGS・XGRIDS Lixel K2活用体験会」開催（日本）
- **何ができるようになったか**: 専用スキャナー「XGRIDS Lixel K2」の実機デモと3D点群処理システムを組み合わせ、測量・現況調査の現場で3DGSをすぐ試せる体験会を7月2日・3日に東京で開催
- **これまでの課題と解決**: 3DGSは導入のハードルが高いと思われがちだったが、専門業者が実機を使った体験会を開くことで、建設・測量業界の現場担当者が直接触れて検討できる機会が広がった
- リンク: https://www.excite.co.jp/news/article/Prtimes_2026-06-18-93846-17/

### 9. Apartments.com（CoStar Group）がMatterport 3D Exteriorsで3DGS外観ツアーに対応
- **何ができるようになったか**: 賃貸物件の「外観」までドローン撮影ベースの3DGSでバーチャルツアー化できるように
- **これまでの課題と解決**: 室内の3Dツアーは普及していたが建物外観・周辺環境の立体表現は手薄だった。3DGSにより外観も滑らかに動き回れる3D体験として提供できるようになった
- リンク: https://radiancefields.com/apartments-com-unveils-matterport-3d-exterior

### 10. 4DViewsがAWE USA 2026でUnity向け4DGSプラグインを発表
- **何ができるようになったか**: 人物のボリュメトリック（立体動画）撮影データを、メッシュ（従来型3D形状）とガウシアンスプラットの両方の形式で同時にUnityへ即時エクスポートできるように
- **これまでの課題と解決**: これまでは撮影データをメッシュかGSのどちらかの形式に絞って書き出す必要があったが、両方を同時出力する「デュアル・パイプライン」により、開発者が用途に応じて使い分けられるようになった
- リンク: https://www.cgw.com/Press-Center/News/2026/4Dviews-unveils-Unity-plug-in-for-volumetric-Gau.aspx
